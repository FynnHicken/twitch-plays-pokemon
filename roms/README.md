# ROMs Ordner

Lege hier deine Pokémon Game Boy oder Game Boy Color ROM-Dateien ab (`.gb` oder `.gbc`).

### Unterstützte Spiele:
- Pokémon Rote Edition (`.gb`)
- Pokémon Blaue Edition (`.gb`)
- Pokémon Gelbe Edition (`.gb`)
- Pokémon Goldene Edition (`.gbc`)
- Pokémon Silberne Edition (`.gbc`)
- Pokémon Kristall-Edition (`.gbc`)
- Jedes andere Game Boy / Game Boy Color ROM!

### Funktionsweise:
1. Das System durchsucht diesen Ordner automatisch beim Start nach `.gb` / `.gbc` Dateien.
2. Wenn mehrere ROMs vorhanden sind, werden Dateien mit "pokemon" im Namen bevorzugt.
3. Falls keine ROM vorhanden ist, startet der Container in einem interaktiven Standby-Modus mit Hinweisen.
